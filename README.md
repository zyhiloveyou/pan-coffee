# 潘咖啡 · 移动端主页

一个手机浏览优先的咖啡馆单页主页，**现代明快风格**（奶白 `#fdf9f2` + 焦糖橙 `#ad5a15`）。

**纯静态、零外部依赖**：没有 CDN、没有外部字体、没有 JS 库，图形全部是内联手写 SVG。放在任何静态托管或直接双击打开都能跑，断网、内网也正常显示。

```
pan-coffee/
├── index.html          页面结构（内容 + 19 个内联 SVG 插画 + SEO/结构化数据）
├── css/style.css       全部样式（移动优先，4 个断点）
├── js/main.js          交互（抽屉菜单、分类切换、滚动显隐、复制地址/微信号）
├── img/                logo 与图标（由你的原图生成，见「替换 logo」）
└── preview/            渲染预览图（非页面必需，可删）
```

## 本地预览

```bash
cd pan-coffee
python3 -m http.server 8080        # 然后手机浏览器访问 http://<电脑局域网IP>:8080
```

直接双击 `index.html` 也能看，但**用真机 + 局域网地址**才能看到固定底栏、抽屉菜单、刘海屏安全区等移动端效果。

### 换成实拍照片

把每个 `<figure class="shot">` 里的 `<div class="shot__art">…内联 SVG…</div>` 整块换成 `<img>` 即可：

```html
<figure class="shot shot--tall">
  <img src="img/bar.jpg" alt="吧台与手冲壶" loading="lazy" decoding="async">
  <figcaption>吧台与手冲壶</figcaption>
</figure>
```

- 建议宽度 800px 上下、压到 150KB 以内；`.shot--tall` 是竖图位，`.shot--wide` 是整行横图，其余是普通方图位。
- 插画位是 2 列（手机）/ 3 列（桌面）自适应网格，换图后比例不会乱。
- 招牌卡片同理：把 `index.html:151-206` 里每张卡片的 `<div class="card__art">…</div>` 换成 `<img>`。

### 替换 logo

logo 由你的原图（`img/logo-original.jpg`，888×888 白底 JPG）加工而来：

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `img/logo.png` | 160×128 | 顶栏 30px 高、页脚 46px 高（白底已转成**透明通道**） |
| `img/favicon-64.png` | 64×64 | 浏览器标签页图标（奶白底 + logo 居中） |
| `img/apple-touch-icon.png` | 180×180 | iOS「添加到主屏幕」图标（同上） |
| `img/logo-original.jpg` | 888×888 | 原始文件存档，方便以后重新裁切 |

加工做了三件事：裁掉四周不均匀的白边（原图内容只占 730×582，且留白不对称）、把白底按覆盖度转成 alpha（顺带把 JPEG 白区噪点阈值到 5% 以下，避免灰雾）、缩放到显示所需的 2–3 倍分辨率。

换成别的 logo 时：

- **透明底 PNG**：直接覆盖 `img/logo.png` 即可。CSS 是 `height: 30px; width: auto`，任意长宽比自适应、不会变形。
- **白底图**：别直接放上去（白色方块压在奶白背景上很明显）。把原图放进项目根目录告诉我，我重新跑一次「裁切 + 白底转透明」；或自己用支持该功能的工具导一次。
- 页脚是深咖色块，logo 是黑色笔画，所以页脚那张底下垫了一块奶白色片（`.footer__logo` 的 `background`）——换深色 logo 时记得改这里。

```html
</li>
```

## 移动端做了哪些针对性处理

- **浮动底栏**：圆角悬浮条，下滑时收起让出阅读空间，上滑或回到顶部立刻出现；底部预留 `env(safe-area-inset-bottom)` 适配 iPhone 手势条。
- **抽屉菜单**：点按展开，背景滚动用 `position:fixed` 锁死（iOS Safari 的 `overflow:hidden` 锁不住，已规避），关闭时精确回到原滚动位置；支持 Esc 关闭、点变暗处关闭、Tab 焦点循环。
- **层级**：遮罩（变暗层）在下、菜单面板在上（面板 `z-index:1`），所以是「背景变暗 + 菜单正常亮度」。
- **菜单分类**：标签栏横向可滑、吸顶在顶栏下方，切换时把选中标签滚到屏幕中间。
- **矮屏手机**（如 iPhone SE，568px 高）：首屏图形隐藏、行距与按钮内距收紧，保证标题和**三个按钮**都在第一屏内、下滑提示不被挤出屏幕。
- **无 JS 也能读**：所有内容都在 HTML 里，JS 只做增强；脚本失效时菜单、豆单、正文照常显示。
- **尊重系统设置**：`prefers-reduced-motion` 下关闭全部动画并让内容立即可见。

## 已实测验证的项

用无头 Chrome 做真实设备仿真（含 meta viewport、触摸、DPR），在 **320×568 / 390×844 / 768×1024 / 1280×900** 下测量：

- 无横向溢出（`scrollWidth == clientWidth == 视口宽`），不会触发移动端「缩放适配」；招牌横滑区与分类标签的横向滚动是有意设计。
- 文字对比度 **31/31 通过 WCAG AA**（正文与小字 ≥ 4.5:1）；按钮、标签、描边 ≥ 3:1。
- 触摸目标：全部 ≥ 24px（WCAG 2.5.8），主要控件 ≥ 44px。
- 交互回归：抽屉开合 / Esc / 点变暗处关闭 / 滚动锁与位置还原 / 锚点跳转 / 分类切换 aria 状态 / 底栏随滚动显隐 —— 全部通过。
- 插画**逐张做了截图像素采样**，确认 19 个 SVG 与深色页脚上的 logo 真实渲染（不是空白）。
- 无控制台报错、无失败请求、**零外部网络请求**（可离线、可内网）。
