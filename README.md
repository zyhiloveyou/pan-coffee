# 潘咖啡 · 移动端主页

一个为手机浏览优先设计的咖啡馆单页主页。日式侘寂风格（灰褐 + 纸感），**纯静态、零外部依赖**（无 CDN、无字体、无 JS 库），放在任何静态托管或本地打开都能跑，断网也正常显示。

```
pan-coffee/
├── index.html          页面结构（含 SEO / 结构化数据 / 内联图标）
├── css/style.css       全部样式（移动优先，4 个断点）
├── js/main.js          交互（抽屉菜单、分类切换、滚动显隐、复制地址）
└── preview/            渲染预览图（非页面必需，可删）
```

## 本地预览

```bash
cd pan-coffee
python3 -m http.server 8080        # 然后手机浏览器访问 http://<电脑局域网IP>:8080
```

直接双击 `index.html` 也能看，但**用真机 + 局域网地址**才能看到固定底栏、安全区（刘海屏）等移动端效果。

预览图：`preview/mobile-hero.png`（首屏）、`preview/mobile-390.png`（全页）、`preview/desktop-1280.png`（桌面）。

### 换成真实照片

把每张 `<figure class="shot">` 里的 `<div class="shot__ph shot__ph--N">` 换成 `<img>` 即可，样式不用动：

```html
<figure class="shot shot--tall">
  <img src="img/bar.jpg" alt="吧台与手冲壶" loading="lazy" decoding="async">
  <figcaption>吧台与手冲壶</figcaption>
</figure>
```

- 建议宽度 800px 左右、压缩到 150KB 以内；`.shot--tall` 是竖图位（高宽比约 3:2 竖版），`.shot--wide` 是整行横图。
- 说明文字是浅色压深色遮罩，换任何照片都清晰；想改成浅底深字，改 `.shot figcaption` 即可。
- 建议另存一份 `<img>` 之外再提供 `img/` 目录，页面本身不需要构建工具。

## 页面包含的区块

首屏（店名 + 看菜单/到店导航）→ 壹 关于潘咖啡 → 贰 招牌推荐（横向滑动卡片）→ 叁 菜单与价格（5 个分类标签）→ 肆 到店信息（地址/营业/电话/地图按钮）→ 伍 店内一角（相册）→ 页脚，外加**固定底部操作栏**：打电话 / 导航到店 / 微信预约。

## 移动端做了哪些针对性处理

- **固定底栏**：下滑时自动让出阅读空间，上滑或回到顶部立刻出现；底部预留 `env(safe-area-inset-bottom)` 适配 iPhone 手势条。
- **抽屉菜单**：点按展开，背景滚动用 `position:fixed` 锁死（iOS Safari 的 `overflow:hidden` 锁不住，已规避），关闭时精确回到原滚动位置；支持 Esc 关闭与 Tab 焦点循环。
- **菜单分类**：标签栏横向可滑、吸顶在顶栏下方，切换时把选中标签滚到中间。
- **模态安全**：`100svh` 避免地址栏伸缩跳动；矮屏手机（如 iPhone SE，568px 高）有专门压缩规则，保证标题与按钮都在第一屏内。
- **无 JS 也能读**：所有内容都在 HTML 里，JS 只做增强；脚本失效时相册、菜单、正文照常显示。
- **尊重系统设置**：`prefers-reduced-motion` 下关闭全部动画并让内容立即可见。

## 已实测验证的项

用无头 Chrome 以真实设备仿真（含 meta viewport、触摸、DPR）在 **320×568 / 390×844 / 768×1024 / 1280×900** 四种视口下测量：

- 无横向溢出（`scrollWidth == clientWidth`），越界元素 0；横向滑动区（招牌卡片、分类标签）为有意设计。
- 文字对比度 **28/28 通过 WCAG AA**（正文/小字 ≥ 4.5:1，灰褐 `#635c50`、苔绿 `#575d4b`、柿色 `#8a4a26` 均已按对比度重新取值）；按钮与标签描边 ≥ 3.4:1（WCAG 1.4.11）。
- 触摸目标：所有按钮/链接 ≥ 24px（WCAG 2.5.8），主要控件 ≥ 44px。
- 交互回归：抽屉开合 / Esc 关闭 / 滚动锁与位置还原 / 锚点跳转后正确落位 / 分类切换 aria 状态 / 底栏随滚动显隐 —— 全部通过。
- 无控制台报错、无失败请求、**零外部网络请求**（可离线、可内网）。
- HTML 标签闭合、id 唯一性、JS 语法、CSS 括号与自定义属性引用均校验通过。

## 部署

任何静态托管都能直接上传（对象存储、Nginx、Vercel/Netlify、GitHub Pages 均可），无需构建。上传 `index.html`、`css/`、`js/`（`preview/` 可不上传）。

几点建议：

- 微信内打开时，底栏「微信预约」复制的是微信号，客人长按粘贴搜索即可，比放二维码更省事；想放二维码可在页脚加一张图片。
- 地图按钮目前直接调起高德/Apple 地图**搜索地址**，不需要 API key。若想内嵌地图，再申请高德或百度地图 JS API 并填入坐标。
- 若要「添加到主屏」，可补一个 `manifest.json` + 图标（当前未包含，避免引入多余请求）。
